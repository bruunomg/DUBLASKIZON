# V87.36 — expressões compartilhadas

- USAR EM compartilha a expressão com qualquer voz da categoria escolhida, sem trocar a seleção nem usar o doador como voz principal.
- SALVAR REAÇÕES disponibiliza as referências cadastradas para Originais, Vozes do sistema e Escolhidas por mim no projeto atual.
- Referências compartilhadas são copiadas para TEXTO PARA FALA/EXPRESSOES COMPARTILHADAS; apagar ou mover o arquivo exportado original não desfaz o cadastro.
- Importação oferece todos os formatos aceitos pelo aplicativo. Primeira leitura de um perfil antigo migra suas referências válidas quando ainda não existe o banco compartilhado.
- Conversão final de timbre para a voz selecionada permanece ativa. Não houve avaliação auditiva de novas expressões; arquivos defeituosos ou formatos não decodificáveis ainda exigem diagnóstico específico.
